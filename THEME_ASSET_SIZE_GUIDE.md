# Lustre Theme Asset Size Guide

Use these recommended sizes when uploading media to the Shopify customizer.

| Asset | Recommended Size | Notes |
| --- | --- | --- |
| Header logo desktop | 240 x 80 px | Upload in `Theme settings > Logo` |
| Header logo mobile | 180 x 60 px | Same logo setting is reused on mobile |
| Hero desktop image | 1920 x 900 px | Upload in the `Lustre hero media` section |
| Hero mobile image | 1080 x 1400 px | Upload in the `Lustre hero media` section |
| Hero desktop video | 1920 x 900 px MP4 | Upload in the `Lustre hero media` section |
| Hero mobile video | 1080 x 1400 px MP4 | Upload in the `Lustre hero media` section |
| Category image | 800 x 800 px | Upload in each `Lustre category slider` block |
| Product image | 1000 x 1000 px | Upload on each Shopify product |
| Mobile footer icon image | 64 x 64 px | Upload in each `Lustre mobile navigation` block |
| Favicon | 32 x 32 px or 64 x 64 px | Upload in `Theme settings > Logo` |

## Shopify Customizer Locations

- Logo: `Online Store > Themes > Customize > Theme settings > Logo`
- Favicon: `Online Store > Themes > Customize > Theme settings > Logo`
- Hero images/videos: `Customize > Home page > Lustre hero media`
- Mobile bottom navbar icons/links: `Customize > any template > Lustre mobile navigation`
- Category images: `Customize > Home page > Lustre category slider`
- Product images/videos: `Shopify Admin > Products > open product > Media`
